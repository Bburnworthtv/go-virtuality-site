Project: Go Virtuality Website Rebuild

Objective
Rebuild govirtuality.com as a premium, editorial, luxury-feeling real estate media website. The current site is fragmented, inconsistent, and dated. The new site must feel intentional, high-end, clean, modern, and conversion-focused without looking like a generic SaaS template.

Primary Business Focus
Go Virtuality offers real estate media services. The live site currently emphasizes:
- Virtual staging
- Residential real estate photography
- Commercial photography
- FAA-certified drone photography and video
- Video walkthroughs

Known Current Pricing To Preserve As Reference
- Virtual staging starts at $99
- 4 virtually staged images for $99
- 3 additional virtually staged images for $50
- Bronze package: $299
- Silver package: $399
- Gold package: $499

Important Brand/Visual Direction
- Do not use a basic SaaS UI style
- Do not use purple or blue hues
- Avoid glassmorphism, glowing cards, startup gradients, dashboards, feature-grid SaaS tropes, and generic “agency template” patterns
- The site should feel luxury, editorial, cinematic, warm, refined, and premium
- Use strong typography, restrained spacing, art direction, asymmetrical composition where helpful, and high-confidence layout choices
- Favor warm neutrals, charcoal, brass, muted olive, sand, ivory, espresso, and stone tones
- The design should feel more like a boutique luxury brand than a software company

Technical Requirements
- Use Next.js 14 with App Router
- Use TypeScript
- Use Tailwind CSS
- Use clean component architecture
- Use server components by default
- Use semantic HTML
- Prioritize accessibility, performance, maintainability, and SEO
- No duplicated content across pages
- Keep content in typed data/config files where practical
- Build for deployment on Vercel

Hosting Assumption
- This project will be deployed on Vercel
- Domain will eventually point to govirtuality.com
- Structure code and environment handling accordingly

Design System Direction
- Create a custom Tailwind theme using CSS variables
- Avoid default Tailwind-looking UI
- Avoid generic cards everywhere
- Prefer layered sections, strong image crops, elegant dividers, tasteful motion, and intentional typography hierarchy
- Mobile and desktop should both feel designed, not merely responsive

Suggested Palette
- Background: warm ivory / soft stone
- Surface: sand / parchment / muted beige
- Text: charcoal / espresso
- Accent: brass / muted gold / olive
- Border: subtle warm gray

Suggested Typography Direction
- Headings should feel editorial and distinctive
- Body type should be calm and readable
- Avoid default system-only feel
- Choose pairings that feel elevated, not trendy SaaS

Page Goals
The site should clearly guide a user from discovery to trust to inquiry.

Primary CTA ideas
- Book a Shoot
- Request Pricing
- Start Your Order
- View Portfolio

Content Rules
- No duplicate page sections copied across multiple routes
- Homepage should summarize, not fully duplicate service pages
- Services page should route, not over-explain
- Pricing should contain pricing details instead of repeating tables everywhere
- FAQ should not become a dumping ground for duplicated sales copy

Implementation Rules
- Build reusable components only where there is true repeated structure
- Avoid premature abstraction
- Keep sections modular and readable
- Use content collections or typed data objects for services, testimonials, pricing, and portfolio
- Write code like a senior engineer: simple, organized, maintainable
- Favor clarity over cleverness

SEO + Content Notes
- Use strong metadata on every page
- Build reusable SEO helpers
- Include structured data where appropriate
- Home, services, pricing, about, and portfolio should all be indexable
- The copy should sound premium, concise, and human
- Avoid keyword stuffing

Motion Direction
- Use restrained motion
- Prefer elegant reveal, fade, slide, and image transitions
- No excessive animation or gimmicks

Luxury UI Guidance
- Think boutique real estate brand, not startup dashboard
- Use negative space intentionally
- Let photography carry weight
- Use fewer UI devices, better executed
- Avoid over-boxing everything
- Avoid sterile corporate layouts
